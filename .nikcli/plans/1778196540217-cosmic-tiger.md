# Nikcli Codebase Exploration Summary

## Overview

Full codebase exploration completed with 10 agents covering all major systems.

## Architecture

### Core Entry Points

- `src/index.ts` - CLI entry using yargs
- `src/server/server.ts` - Hono-based HTTP server
- `src/cli/cmd/run.ts` - TUI session runner
- `src/cli/cmd/serve.ts` - Server command

### Agent System (`src/agent/agent.ts`)

**Primary Agents**: ralph, build, plan, general
**Subagents**: explore, fast-explore, planner, researcher, code-reviewer, debugger, test-runner, refactor, delegator

### Tool System (`src/tool/`)

**20+ Built-in Tools**: bash, read, write, edit, glob, grep, tree, monitor, task, question, skill, delegation, delegator, memory_search, generate_image, batch, websearch, webfetch, opentui

### Session & Storage

- Session: `["session", projectID, sessionID]`
- Messages: `["message", sessionID, messageID]`
- Parts: `["part", messageID, partID]`
- Uses Effect-based storage with JSON backend

### SDK (`packages/sdk/`)

- Auto-generated from OpenAPI via `bun dev generate`
- Build: `./packages/sdk/js/script/build.ts`
- Client: `createNikcliClient()` in `packages/sdk/js/src/v2/client.ts`

### UI/TUI (`src/cli/cmd/tui/`)

- SolidJS + OpenTUI
- Provider hierarchy pattern
- Dialog system with stack-based overlays
- Routes: home, session, changes, tree, git-graph, github, plugin

### Plugin System (`src/plugin/`)

- Server plugins via `@nikcli-ai/plugin` SDK
- TUI plugins via `@nikcli-ai/plugin/tui`
- Hooks: config, event, auth, tool, provider

### Auth (`src/auth/`)

- OAuth, API key, Well-Known auth types
- Stores: `~/.local/share/nikcli/auth.json`
- Provider auth integration

### Testing (`test/`)

- Bun test runner
- `.test.ts` suffix naming
- Effect-based test utilities
- Benchmarks: `.benchmark.test.ts`

## Build Commands

- `bun run dev` - Run in browser mode
- `bun run build` - Build multi-platform binaries
- `bun run typecheck` - TypeScript with tsgo
- `bun run lint` - oxlint
- `bun test` - Run tests
