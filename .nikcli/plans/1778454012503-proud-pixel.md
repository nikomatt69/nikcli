# FFF Effect Integration Plan

## Summary

Integrate the FFF file search module into the Effect system for better context management and type safety. Start with src/file/fff.ts first.

---

## Current State

### fff.ts Issues

1. **Uses Instance.state()** - Works but not Effect-native
2. **No proper error types** - Returns `undefined` for failures instead of typed errors
3. **No Layer composition** - Can't be composed with other Effect services
4. **State is in closure** - Hard to test and mock

### Target Pattern

Following the pattern from:

- `src/file/index.ts` - File.Service with Layer.scoped
- `src/filesystem/index.ts` - AppFileSystem with Layer.effect
- `src/project/instance.ts` - Instance state management

### Step 3: Implement Layer

```typescript
const layer = Layer.scoped(
  Service,
  Effect.gen(function* () {
    const ctx = yield* InstanceState.context
    const dir = ctx.directory
    const dbDir = path.join(Global.Path.cache, "fff", projectKey(dir))

    // Initialize FileFinder with error recovery
    const created = FileFinder.create({
      basePath: dir,
      frecencyDbPath: path.join(dbDir, "frecency.mdb"),
      historyDbPath: path.join(dbDir, "history.mdb"),
      aiMode: true,
    })

    if (!created.ok) {
      if (isLMDBError(created.error)) {
        await fs.rm(dbDir, { recursive: true, force: true })
        // retry logic...
      }
      return yield* Effect.fail(new FFFError(created.error))
    }

    const finder = created.value

    return Service.of({
      available: Effect.succeed(true),
      waitForScan: (timeoutMs = 5000) => Effect.sync(() => {
        const result = finder.waitForScan(timeoutMs)
        return result.value ?? false
      }),
      files: (input) => /* ... */,
      // ...
    })
  })
)

export const defaultLayer = layer
```

## Notes on Integration Study

The integration design follows these patterns from the codebase:

1. **Context.Tag pattern** - Like File.Service, Session.Service
2. **Layer.scoped** - Like File layer in file/index.ts
3. **InstanceState.make** - For per-instance caching
4. **Error types** - Custom errors extend Error like FFFError
