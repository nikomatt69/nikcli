## Package Template (each plugin)

### package.json

```json
{
  "name": "@nikcli-ai/plugin-starwars",
  "version": "1.0.0",
  "description": "Star Wars theme for nikcli TUI",
  "type": "module",
  "targets": ["tui"],
  "exports": {
    ".": {
      "import": "./dist/plugin.js",
      "types": "./dist/plugin.d.ts"
    }
  },
  "nikcli": {
    "tui": "./dist/plugin.js"
  },
  "peerDependencies": {
    "@nikcli-ai/plugin": "workspace:*"
  },
  "devDependencies": {
    "typescript": "^5.0.0"
  }
}
```

### src/plugin.ts Template

```typescript
import type { TuiPlugin, TuiPluginModule } from "@nikcli-ai/plugin/tui"

// Theme JSON imported at build time
import themeData from "./theme.json"

const PLUGIN_ID = "nikcli:starwars"

const tui: TuiPlugin = async (api) => {
  // 1. Install bundled theme
  await api.theme.install(themeData)

  // 2. Register commands
  api.command.register(() => [
    {
      title: "Toggle Star Wars Theme",
      value: "theme.starwars.toggle",
      category: "Themes",
      onSelect() {
        api.theme.set(PLUGIN_ID)
        api.ui.toast({ message: "May the Force be with you" })
      },
    },
  ])

  // 3. Register UI slots (optional)
  api.slots.register({
    order: 100,
    slots: {
      home_logo() {
        return <StarWarsLogo />
      },
    },
  })

  // 4. Subscribe to events (optional)
  api.event.on("session.start", () => {
    console.log("A long time ago in a galaxy far, far away...")
  })
}

export default {
  id: PLUGIN_ID,
  tui,
} as TuiPluginModule & { id: string }
```

## Spotify Plugin Details

The Spotify plugin (`nikcli-plugin-spotify`) will include:

### Features

- **Now Playing**: Display current track, artist, album art (ASCII)
- **Controls**: Play, pause, skip, previous, volume
- **Search**: Search Spotify library
- **Playlists**: Browse and play playlists
- **Queue**: Manage playback queue

### Authentication (PKCE OAuth)

Following the pattern from the vault-tec plugin repo:

1. Open browser for Spotify OAuth
2. Local callback server receives code
3. Exchange for access/refresh tokens
4. Store tokens securely in kv store

### 2. Create Unified Extensions Dialog Component

**New file**: `packages/nikcli/src/cli/cmd/tui/component/dialog-extensions/index.tsx`

The dialog will have TWO tabs:

- **"Installed"** - Shows currently installed plugins + MCP servers (merge of existing data)
- **"Catalog"** - Shows curated catalog with install button

**Key UI Elements**:

- Tab switching (`Tab` key or click)
- Category headers (Plugins section vs MCP section)
- Visual distinction via icons:
  - Plugin icon: `⬡` (hexagon)
  - MCP icon: `◈` (diamond)
- Status indicators:
  - `✓ enabled` (green)
  - `○ disabled` (gray)
  - `✗ error` (red)
  - `↗ install` (blue)

**Keybinds**:
| Key | Action |
|-----|--------|
| `Space` | Toggle enable/disable (Installed tab) |
| `i` | Install selected (Catalog tab) |
| `Tab` | Switch between Installed/Catalog |
| `↑/↓` | Navigate list |

### 3. Create Dedicated MCP Server Components

**New file**: `packages/nikcli/src/cli/cmd/tui/component/dialog-extensions/mcp-server.tsx`

## Implementation Approach: Hybrid

- **Curated hardcoded list**: 15-20 popular plugins/MCPs ship with nikcli for fast access
- **Custom npm install**: Advanced users can install any npm package via the same dialog

This gives the best of both worlds - immediate value out of the box, plus full flexibility.

1. **Start TUI**: `bun run dev` in packages/nikcli
2. **Open Extensions**: Press `Ctrl+P` then type "extensions" or use command palette
3. **Test Installed tab**: See all installed plugins and MCP servers
4. **Test Catalog tab**: Browse curated list
5. **Test install**: Select an item and press `i` to install
6. **Test toggle**: Select an installed item and press `Space` to toggle
7. **Verify visual distinction**: Plugins vs MCP sections are clearly separated
