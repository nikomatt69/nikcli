## B5: Wire `registerDisposer()` to subsystems

The `registerDisposer()` pattern exists in `src/project/instance.ts` but has **zero call sites**. Most subsystems use `Instance.state()` with dispose callbacks — those are already handled. The gap is **event subscriptions created outside of `Instance.state()` callbacks**.

### Call site: `src/tool/task.ts`, `subscribeDelegationProgress()` usage

The `unsubProgress()` from `subscribeDelegationProgress()` in `launchBackgroundSubtask()` is called in the `.then()` chain, but if an exception fires before that point, the subscription leaks until delegation finalization. Register the disposer for deterministic cleanup:

```typescript
// Around line 267, after: const unsubProgress = subscribeDelegationProgress(...)
Instance.registerDisposer(unsubProgress)
```

Note: This requires `Instance` to be accessible in the context. Check that `App.provide()` or `context` gives access at that call site.

### Remaining potential call sites (defer)

Other candidates (`src/brain/`, `src/command/`, `src/file/`) would benefit from `registerDisposer()` but require deeper analysis of whether they currently leak subscriptions. Defer to a follow-up pass.

## B6: Delegation adaptive follow-up loop

**Current flow:** Subagents run → `waitForSettled()` → `collectResults()` → one delegator prompt → done.

**Goal:** Replace the single-shot delegator call with a loop where the delegator can spawn follow-up tasks or finalize.

### File: `src/tool/task.ts`

Replace lines 290–342 (the single delegator `.then()` chain) with a for loop (max 3 iterations):

```typescript
const MAX_ITERATIONS = 3
let accumulatedResults = synthesisItems
const sessionSummaries: string[] = []

for (let i = 0; i < MAX_ITERATIONS; i++) {
  const resultsText = accumulatedResults
    .map((item) => {
      const details = item.resultSummary ?? item.progressSummary ?? item.error ?? "(no output)"
      return `- ${item.id} [${item.status}] @${item.agent}\n${details}`
    })
    .join("\n\n")

  const isLastRound = i === MAX_ITERATIONS - 1

  const wakeText = [
    i === 0 ? `Background task completed with status: **${status}**.` : `## Follow-up Round ${i + 1}`,
    "",
    `Agent: @${params.agent.name}`,
    `Task: ${params.prompt}`,
    "",
    "## Accumulated Results",
    resultsText,
    "",
    ...(sessionSummaries.length > 0
      ? ["", "## Previous Synthesis", sessionSummaries[sessionSummaries.length - 1]]
      : []),
    "",
    isLastRound
      ? "**This is the final round. You must finalize.**"
      : "**Analyze results and decide: finalize now or continue with follow-up work.**",
    "",
    "## Your Decision (required)",
    "Respond with: **Action:** finalize | continue",
    "**Reason:** <one sentence>",
  ].join("\n")

  const result = await SessionPrompt.prompt({
    messageID: Identifier.ascending("message"),
    sessionID: delegatorSession.id,
    model: params.model,
    agent: "delegator",
    tools: {
      todowrite: false,
      todoread: false,
      task: !isLastRound, // Allow spawning in non-final rounds only
    },
    parts: [{ type: "text" as const, text: wakeText }],
  })

  const summary = await summarizeSubtaskSession(delegatorSession.id, result)
  sessionSummaries.push(summary.text)

  const text = summary.text ?? ""
  const actionMatch = text.match(/\*\*Action\*\*[\s:]+(finalize|continue)/i)
  const action = (actionMatch?.[1]?.toLowerCase() ?? "finalize") as "finalize" | "continue"

  if (action === "finalize" || isLastRound) break

  // Wait for new spawns, collect results, loop
  await Delegation.waitForSettled(params.parentSessionID).catch(() => undefined)
  const newResults = await Delegation.collectResults(params.parentSessionID).catch(() => [])
  const seen = new Set(accumulatedResults.map((r) => r.id))
  accumulatedResults.push(...newResults.filter((r) => !seen.has(r.id)))
}

// Finalize delegator delegation
const finalSummary = sessionSummaries[sessionSummaries.length - 1] ?? ""
const finalErr = summary.assistant?.error
const finalStatus = finalErr ? (MessageV2.AbortedError.isInstance(finalErr) ? "cancelled" : "error") : "complete"
await Delegation.finalize(
  delegatorDelegation.id,
  finalStatus,
  finalSummary,
  finalErr ? extractErrorMessage(finalErr) : undefined,
)
```
