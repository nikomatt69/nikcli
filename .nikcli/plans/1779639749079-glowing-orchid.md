# Nikcli vs Opencode: Comprehensive Integration Plan

## Context

User asked to compare nikcli with opencode and integrate best patterns. Full analysis completed across session module and related systems.

## Comprehensive Comparison Matrix

### 1. SESSION MODULE

| --------------------- | ------------------- | ------------------------------------------- | -------------------- |
| **Storage**           | File-based JSON     | SQLite + drizzle-orm                        | Future consideration |

### 2. INSTRUCTION SYSTEM (Priority High)

**Nikcli Issues:**

- No claims tracking (can attach same instruction multiple times)
- No upward walk from file being read
- Lower concurrency for file reading (2 vs 8)

**Opencode Pattern (lines 178-220):**

```typescript
// Walks UP from file being read, finds nearby AGENTS.md/CLAUDE.md
while (current.startsWith(root) && current !== root) {
  const found = yield* find(current)
  if (!found || found === target || sys.has(found) || already.has(found)) {
    current = path.dirname(current)
    continue
  }
  // Track claims per messageID to avoid duplicates
  let set = s.claims.get(messageID)
  if (set.has(found)) { ... }
  set.add(found)
  content = yield* read(found)
}
```

**Nikcli Current (lines 183-201):**

```typescript
// No upward walk, no claims tracking
for (const p of msgPaths) {
  if (loaded.has(p)) continue // Only checks this message
  // No tracking across messages
}
```

**Improvement Needed:**

1. Add `claims: Map<MessageID, Set<string>>` tracking
2. Add upward walk from filepath
3. Increase concurrency: 8 for files, 4 for URLs

### 3. OVERFLOW/COMPACTION (Priority Medium)

**Nikcli (overflow.ts):**

```typescript
export function isOverflow(input: { tokens: MessageV2.Assistant["tokens"]; model: Provider.Model }) {
  // Simple check, no reserved buffer config
  const count = input.tokens.total || input.tokens.input + input.tokens.output
  return count >= input.model.limit.input
}
```

**Opencode (overflow.ts):**

```typescript
const COMPACTION_BUFFER = 20_000
export function usable(input: { cfg: Config.Info; model: Provider.Model; outputTokenMax?: number }) {
  const reserved = input.cfg.compaction?.reserved ?? Math.min(COMPACTION_BUFFER, maxOutputTokens(...))
  return input.model.limit.input
    ? Math.max(0, input.model.limit.input - reserved)
    : Math.max(0, context - maxOutputTokens)
}
```

**Improvement:** Add `cfg.compaction?.reserved` configuration option

---

### 4. STORAGE (Priority Low - Future)

**Nikcli:** File-based with simple Cache namespace
**Opencode:** SQLite with drizzle-orm, proper indexes

**Opencode Uses:**

- `RcMap` for thread-safe concurrent access
- `TxReentrantLock` for transactions
- Proper cascade deletes via foreign keys

**Note:** This is a major migration - not recommended for now.

---

### 5. RUN STATE (Priority Low)

**Nikcli:** Simple Map in Session namespace
**Opencode:** Runner pattern with Latch, proper cleanup

**Opencode Pattern:**

- Uses `Runner.Runner<MessageV2.WithParts>` with callbacks
- Tracks busy/idle states properly
- Cancels background jobs on session cancel

---

### 6. LLM LAYER (Priority Medium)

**Nikcli:** Single ai-sdk based LLM
**Opencode:** ai-sdk + native-route (`@opencode-ai/llm/route`)

**Opencode Has:**

- `LLMAISDK` for standard providers
- `LLMNativeRuntime` for native providers
- `WebSocketExecutor` for real-time

## Implementation Plan (Prioritized)

### PHASE 1: Quick Wins (30 min)

#### 1. Instruction Claims Tracking

**File:** `src/session/instruction.ts`

Add `claims: Map<string, Set<string>>` to track attached files per message:

```typescript
// Change state from simple Map to include claims
state = {
  loaded: new Map<string, Set<string>>(), // messageID -> Set<filepath>
}

// In resolve():
const existing = state.get(messageID) ?? new Set()
if (existing.has(filepath)) return []
existing.add(filepath)
state.set(messageID, existing)
```

**File:** `src/session/instruction.ts`

```typescript
let current = path.dirname(filepath)

  const found = yield * find(current)
  if (found && !already.has(found)) {
    // Attach found

}
```
