# Nikcli vs Opencode: Comprehensive Integration Plan

## Context

User asked to compare nikcli with opencode and integrate best patterns across the entire codebase. Full architectural analysis completed.

---

## Executive Summary

### Architectural Philosophy

| Aspect       | Nikcli               | Opencode                  |
| ------------ | -------------------- | ------------------------- |
| **Paradigm** | Bun-first, pragmatic | Effect-native, enterprise |
| **Storage**  | File-based JSON      | SQLite + drizzle-orm      |
| **Provider** | AI SDK only          | AI SDK + native-route     |
| **Flags**    | Simple boolean       | RuntimeFlags with Config  |
| **Bridge**   | Basic layer system   | EffectBridge with ALS     |

### Key Finding

**Opencode is more "enterprise-grade" with better:**

- Type safety (Effect.Schema everywhere)
- AsyncLocalStorage preservation (EffectBridge)
- Runtime flags configuration (RuntimeFlags.Service)
- Storage transactions (SQLite + RcMap)

**Nikcli is more "developer-friendly" with:**

- Simpler deployment (no DB migration)
- Faster iteration (file-based storage)
- Better Bun integration
- Lighter footprint

## Detailed Feature Comparison

### 1. EFFECT USAGE

| Feature            | Nikcli          | Opencode              | Recommendation |
| ------------------ | --------------- | --------------------- | -------------- |
| Service Definition | Context.Service | Context.Service       | Parity ✅      |
| Layer Pattern      | Layer.effect    | Layer.effect          | Parity ✅      |
| InstanceState      | Basic Map       | Proper scoped cache   | Improve        |
| EffectBridge       | N/A             | Full ALS preservation | **Adopt**      |
| Effect.fn usage    | Limited         | Extensive             | Expand         |

**Opencode's EffectBridge Pattern:**

```typescript
// Preserves AsyncLocalStorage across Effect boundaries
export const fromPromise = <T>(fn: () => Promise<T>) =>
  Effect.gen(function* () {
    const workspace = yield* WorkspaceRef
    return yield* Effect.promise(() => restoreWorkspace(workspace, () => fn()))
  })
```

**Nikcli Should Adopt:**

1. EffectBridge for callback interop
2. `Effect.fn` for memoization
3. `Effect.fnUntraced` for non-traced operations

### 2. RUNTIME FLAGS

| Feature     | Nikcli         | Opencode             | Recommendation    |
| ----------- | -------------- | -------------------- | ----------------- |
| Config      | Flag namespace | RuntimeFlags.Service | **Adopt pattern** |
| Type Safety | Minimal        | Full Config mapping  | Improve           |
| Composition | N/A            | Config.all()         | Adopt             |

**Opencode Pattern:**

```typescript
export class Service extends ConfigService.Service<Service>()("@opencode/RuntimeFlags", {
  experimentalPlanMode: enabledByExperimental("OPENCODE_EXPERIMENTAL_PLAN_MODE"),
  enableParallel: Config.all({ enabled: bool("..."), legacy: bool("...") }).pipe(...)
}) {}
```

**Nikcli Should Adopt:**

1. RuntimeFlags.Service pattern
2. Config.all() for flag composition
3. Better typing

### 3. TOOL SYSTEM

| Feature          | Nikcli                  | Opencode                | Recommendation |
| ---------------- | ----------------------- | ----------------------- | -------------- |
| Definition       | Tool.define()           | Tool.define()           | Parity ✅      |
| Truncation       | In tool.execute         | Centralized in wrap     | **Improve**    |
| Metadata typing  | Record<string, unknown> | Generic constraints     | Improve        |
| InvalidArgsError | Manual                  | Schema.TaggedErrorClass | **Adopt**      |

**Opencode Tool Wrap Pattern:**

```typescript
toolInfo.execute = (args, ctx) => {
  // Centralized truncation in one place
  const truncated = yield * truncate.output(result.output, {}, agent)
  return { ...result, output: truncated.content }
}
```

**Nikcli Should Adopt:**

1. Centralized truncation in tool.ts wrap
2. InvalidArgumentsError with formatValidationError
3. Generic metadata constraints
