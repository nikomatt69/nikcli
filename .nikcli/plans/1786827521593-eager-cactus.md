Pattern already proven: check route → declare if missing → `bun run generate:httpapi-clients` → move call site → curl against `bun run src/index.ts serve --port …` → update `specs/tui-package.md` in the same commit.

Encoder rejects `undefined` as empty 400. Optional fields: `Schema.optional`. Absent documents: encode `null`.

### 1a leftover — OAuth without `UserDB`

`Account.poll` already returns `accessToken`. `Auth.resolveBearer` already accepts that JWT and `externalSessionForToken` calls `ensureExternalUser` on the server.

Finish:

1. After poll, `UserSession.save(session.accessToken)` then `UserApi.me(sdk)` — no `UserDB` in the TUI.
2. Invert `Account.login` / `poll` / `active` / `get` as host props (`startAccountLogin`, `pollAccountLogin`, `getActiveAccount`) so `@/account` and `@/effect` leave `dialog-account-login.tsx` and `dialog-profile.tsx`. Same shape as `upgradeNow`.
3. Confirm no remaining `UserDB` import under `src/cli/cmd/tui` except host files.

### 1b. Speak / OpenRouter catalog

`dialog-speak-model.tsx` imports `@/tool/speak/openrouter` for `OPENROUTER_VOICES_LIST` + `openRouterProvider`. Voices are a constant table — same move as ElevenLabs (`@nikcli-ai/util/tts/elevenlabs`).

- Move the voice list + provider object that does not read auth into `@nikcli-ai/util/tts/openrouter`.
- `getAudioModels` reads auth through `@/effect` — do **not** pull that into util. Either:
  - invert as a host prop (`listAudioModels`), or
  - add `GET /provider/openrouter/audio-models` (or under `/tui/`) if more than one client needs it.
- Prefer host invert unless desktop will need the list immediately.

`prompt/index.tsx` `runAuth(Auth.get("openrouter"))` is the same class: invert to a host `getProviderAuth(id)` or use an existing provider-auth route if one already returns the key to the TUI. Do not put API keys into a new public catalog endpoint.

`plugin/shared` + `plugin/meta` helpers that are pure (specifier parse, compatibility) go to `@nikcli-ai/util` if they have no Instance dependency; do not move the installer.

## Working rules

- One service / one phase boundary per commit. Contract change updates its spec in the same commit.
- `bun run generate:httpapi-clients` whenever a group changes; commit generated output.
- Typecheck **once** at the end of a phase, not after every file.
- Curl new or moved routes against a real `serve`. Creating mobile tokens or users writes real stores — revoke / delete after.
- Do not verify with the simulation harness.
- Ask before git commits and before any DB mutation outside tests.
