# Analytics Dialog Redesign Plan

## Overview

Redesign `dialog-analytics.tsx` to match the visual style shown in the reference screenshots with:

- Global stats in a prominent header box with dividers (Large layout)
- Both line charts AND bar charts for usage data
- Clean modern layout with visual hierarchy

## User Preferences

- **Chart type**: Both line chart and bar chart where appropriate
- **Layout size**: Large - more space for better visibility
