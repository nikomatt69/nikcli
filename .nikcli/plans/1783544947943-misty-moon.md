### A1. F1.2 provider-error → retryable APIError (Week 1) — **FIRST PR**

**Verified path (broken today):**

```
provider-error { message, retryable?, providerMetadata? }   # packages/llm schema/events.ts:114-119
  → mapLLMEvent L215-216: throw new Error(event.message)   # loses retryable
  → processor catch → MessageV2.fromError                   # message-v2.ts:947+
  → case Error → EventError.unknown                         # L1022-1023
  → SessionRetry.retryable: only JSON-parse heuristics      # retry.ts:99-118
```

**Target path:**

```
provider-error → throw APICallError({ message, isRetryable, statusCode?, responseBody? })
  → fromError case APICallError.isInstance (L977-1019)
  → name: APIError, data.isRetryable preserved
  → SessionRetry.retryable returns message for 429/5xx/retryable
```

**Implementation (adapter-only, no processor edit):**

1. Import `APICallError` from `@ai-sdk/provider` (same as `message-v2.ts` L6).
2. Replace L215-216 with helper `throwProviderError(event)`:
   - `message` = event.message
   - `isRetryable` = `event.retryable === true` OR heuristic on message (rate limit / throttle / 429 / overloaded)
   - `statusCode` = extract from `providerMetadata` if present (optional; default undefined)
   - `url` optional empty; required fields per APICallError ctor
3. Update test `"throws on provider-error"` → assert `APICallError.isInstance` + `isRetryable` for:
   - `{ message, retryable: true }` (Bedrock throttle shape)
   - `{ message: "rate limited" }` without flag (heuristic or false — pick one, document)
   - non-retryable permanent error
4. Add retry unit: `SessionRetry.retryable(MessageV2.fromError(apiCallErr, {providerID}))` defined for retryable case.

## A1 implementation sketch (copy-ready)

Installed `APICallError` requires `message`, `url`, `requestBodyValues` (`@ai-sdk/provider` d.ts). Import from `@ai-sdk/provider` (or `ai` re-export like `message-v2.ts`).

```ts
// llm-event-adapter.ts
import { APICallError } from "@ai-sdk/provider"

export function providerErrorToAPICallError(
  event: Extract<LLMEvent, { type: "provider-error" }>,
): APICallError {
  const message = event.message || "Provider error"
  const heuristic = /rate.?limit|throttl|overloaded|too many requests|\b429\b|\b503\b|\b529\b/i.test(message)
  const isRetryable = event.retryable === true || (event.retryable !== false && heuristic)
  return new APICallError({
    message,
    url: "nikcli://native-llm/provider-error",
    requestBodyValues: undefined,
    statusCode: /* optional extract from providerMetadata */,
    isRetryable,
  })
}

case "provider-error":
  throw providerErrorToAPICallError(event)
```

**Tests to add** in `test/session/llm-event-adapter.test.ts`:

- throw is `APICallError.isInstance` with `retryable: true`
- `retryable: false` → `isRetryable === false`
- heuristic throttle message without flag → retryable
- `MessageV2.fromError(err) → name APIError` + `SessionRetry.retryable` defined / undefined
