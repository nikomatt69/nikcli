# Effect Migration Plan - nikcli Package

## Context

Migration from `import z from "zod"` to Effect Schema as source-of-truth, with Zod derived via `zodObject()` / `zod()` from `@/util/effect-zod`.

**Progress**: See `specs/effect/schema.md` for completed slices.

**Goal**: Complete Phase P (session domain + config root + route DTOs) and Phase G (ScopedCache replacement).

### Slice 0.1: Fix FieldsToShape in effect-zod.ts

**File**: `src/util/effect-zod.ts`

**Change**: Extend `FieldToShape` / `FieldsToShape` to handle recursive types:

```typescript
// Add to FieldToShape type:
F extends Schema.Struct<infer Fields>
  ? z.ZodObject<{ [K in keyof Fields]: FieldToZod<Fields[K]> }>
  : F extends Schema.Array<infer E>
    ? z.ZodArray<FieldToZod<E>>
    : F extends Schema.optional<infer X>
      ? z.ZodOptional<FieldToZod<X>>
      // existing fallback
```

**Tests**: `test/util/effect-zod.test.ts` - add test for nested Struct → ZodObject mapping.

## Phase G: ScopedCache Replacement

### Slice G.1: Implement ScopedCache in instance.ts

**File**: `src/project/instance.ts`

**Current**: `Map<string, Promise<Context>>` with manual deduplication

**Target**: `Effect.ScopedCache<string, Context>` (pattern from `src/effect/instance-state.ts`)

**Design** (from MASTER-PLAN.md):

```typescript
const cache = ScopedCache.make({
  capacity: Number.MAX_SAFE_INTEGER,
  timeToLive: Duration.infinity,
  lookup: (directory) =>
    Effect.acquireRelease(makeContextEffect(directory), (_, exit) => Effect.promise(() => runDisposers(exit))),
})
```

**Key methods**:

- `Instance.provide({directory, init?, fn})` → uses `cache.get(normalizeDirectory(directory))`
- `Instance.dispose(dir)` → `cache.invalidate(dir)` (scope finalizer fires disposers)
- `Instance.disposeAll()` → `cache.invalidateAll()`
