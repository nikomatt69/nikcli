## Step 4 — B.2: Remove the legacy `instanceof` chain from `server.ts:196-211` (NEW)

**File:** `packages/nikcli/src/server/server.ts` (1139 lines)

**Current state (verified):** `app.onError((err, c) => {...})` at lines 182-220:

- Lines 189-195: `__http` marker honor (keep)
- Line 196: `if (err instanceof Session.BusyError)` → 409 (REMOVE)
- Line 198: `if (err instanceof Storage.NotFoundError)` → 404 (REMOVE)
- Line 200: `if (err instanceof Provider.ModelNotFoundError)` → 400 (REMOVE)
- Line 208: `if (err instanceof Vcs.PatchApplyError)` → 400 (REMOVE)
- Line 210: `if (err instanceof Error && err.name.startsWith("Worktree"))` → 400 (REMOVE)
- Line 212: `if (err instanceof HTTPException) return err.getResponse()` (KEEP)
- Lines 213-219: `Unknown` 500 fallback (KEEP)

**Sub-steps:**

### 4.1 — Remove the 5 `instanceof` chain entries

- Delete lines 196-211 entirely.
- The middleware becomes:
  ```
  if ("__http" in err) → return c.json({ name, data }, { status })
  if (err instanceof HTTPException) → return err.getResponse()
  log.error("unhandled", { cause: Cause.pretty(cause) })
  return c.json({ name: "Unknown", data: { message: ... } }, { status: 500 })
  ```

### 4.2 — Verify wire-format preservation

- Compare the per-route response body shape before/after for the 5 chain entries (`Session.BusyError → 409 { name, data: { sessionID, message } }`, etc.) via the existing Hono tests.
- If a body shape changes, fix it by re-introducing the helper call at the route level (Step 5), not at the middleware.

- `rg -n "err\.name\.startsWith\(\"Worktree\"\)" packages/nikcli/src/server/server.ts` returns 0.

## Step 5 — B.3: Migrate all 19 route files to `Effect.catchTag` with `httpapi/errors` helpers (NEW, large)

**Files:** all 19 Hono route files in `packages/nikcli/src/server/routes/`. List:

- `session.ts`, `config.ts`, `provider.ts`, `mcp.ts`, `file.ts`, `pty.ts`, `permission.ts`, `project.ts`, `question.ts`, `tui.ts`, `tool.ts`, `vcs.ts`, `formatter.ts`, `worktree.ts`, `share.ts`, `experimental.ts`, `event.ts`, `global.ts`, `health.ts` (verify exact list at execution time).

**Per-route pattern:**

```ts
import { badRequest, notFound, conflict } from "../httpapi/errors"

const result = runSomething(
  Effect.gen(function* () {
    // ...service call...
  }).pipe(
    Effect.catchTag("StorageNotFoundError", (e) => notFound(e.message)),
    Effect.catchTag("ProviderModelNotFoundError", (e) =>
      badRequest("ModelNotFound", { providerID: e.providerID, modelID: e.modelID, suggestions: e.suggestions }),
    ),
    Effect.catchTag("SessionBusyError", (e) => conflict("SessionBusy", { sessionID: e.sessionID })),
    // ...etc
  ),
)
```
