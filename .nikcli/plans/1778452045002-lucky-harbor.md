# Fix: Pass parentAgentName to wakeParentSession

## Problem

In `wakeParentSession` (task.ts:548), the call to `sessionPrompt.prompt` only passes `sessionID` and `parts`, without `agent`. In `createUserMessage` (prompt.ts:1418), the agent resolves via `input.agent ?? (await defaultAgent())` — typically "build".

This causes two issues when a background task wakes the parent:

1. **Plan mode**: `insertReminders` (prompt.ts:1833) compares `input.agent.name` with last assistant's agent; if parent was "plan" but wake resolves to "build", BUILD_SWITCH is injected
2. **Tool permissions**: `loop()` (prompt.ts:870) uses `agent = await agentRequired(lastUser.agent)` and `resolveTools({ agent, ... })`; without correct agent, wrong tools/permissions are used

## Solution

Pass `parentAgentName` from `ctx.agent` to `wakeParentSession` and include it in the `sessionPrompt.prompt` call.

## Files to modify

- `packages/nikcli/src/tool/task.ts`

## Implementation steps

### 1. Extend `wakeParentSession` signature

Add `parentAgentName` parameter and pass it to `sessionPrompt.prompt`:

```typescript
async function wakeParentSession(
  parentSessionID: string,
  parentAgentName: string,
  result: {
    jobId: string
    delegationId: string
    delegatorDelegationId: string
    description: string
    status: string
    summary: string
  },
) {
  // ...
  await runPromiseWithLayer(
    SessionPrompt.defaultLayer,
    withCurrentInstance(
      Effect.gen(function* () {
        const sessionPrompt = yield* SessionPrompt.Service
        return yield* sessionPrompt.prompt({
          sessionID: parentSessionID,
          agent: parentAgentName, // ← add this
          parts: [{ type: "text", text: lines.join("\n") }],
        })
      }),
    ),
  )
}
```

### 2. Add `parentAgentName` to `launchBackgroundSubtask` params

```typescript
async function launchBackgroundSubtask(params: {
  // ... existing fields ...
  parentAgentName: string  // ← add this
}): Promise<BackgroundTaskResult> {
```

### 3. Update call sites in `launchBackgroundSubtask`

Both `.then` and `.catch` call `wakeParentSession` (lines 803-810, 815-822). Pass `params.parentAgentName`.

### 4. Update call site in `runSubtask`

At line 937-951 where `launchBackgroundSubtask` is called, pass `ctx.agent?.name ?? "build"` as `parentAgentName`:

```typescript
const backgroundTask = await launchBackgroundSubtask({
  // ... existing fields ...
  parentAgentName: ctx.agent?.name ?? "build",
})
```
