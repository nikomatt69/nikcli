## Execution Plan

### Step 1 — Write diff to temp file

```bash
git diff HEAD --no-color > /tmp/ultrareview_diff_$(date +%s).patch
```

Also include untracked new files by appending them with `git diff --no-index /dev/null <file>`.

Write context file at `/tmp/ultrareview_ctx_<ts>.txt` with scope + file list.

### Step 2 — Launch 4 parallel monitor jobs

All launched simultaneously in a single message turn:

| Job        | Role env var                   | Title                      |
| ---------- | ------------------------------ | -------------------------- |
| Reviewer 1 | `ULTRAREVIEW_ROLE=bugs`        | `ultrareview: bugs`        |
| Reviewer 2 | `ULTRAREVIEW_ROLE=security`    | `ultrareview: security`    |
| Reviewer 3 | `ULTRAREVIEW_ROLE=performance` | `ultrareview: performance` |
| Reviewer 4 | `ULTRAREVIEW_ROLE=patterns`    | `ultrareview: patterns`    |

Each runs:

```
ULTRAREVIEW_ROLE=<role> ULTRAREVIEW_DIFF=/tmp/ultrareview_diff_<ts>.patch ULTRAREVIEW_CTX=/tmp/ultrareview_ctx_<ts>.txt nikcli run --agent ultrareview-reviewer --no-tui
```

`wake: true` on all 4 monitors.

### Step 3 — Collect results

- Read each log file as monitors complete
- Verify all 4 exit codes = 0

### Step 4 — Synthesize

1. Read all 4 reviewer outputs
2. De-duplicate findings (same file + same issue)
3. Boost confidence for findings flagged by 2+ reviewers
4. Discard speculative / unverifiable findings
5. Clean up temp files

### Step 5 — Output format

```
### [SEVERITY] Short title
**File:** `path/to/file.ts` (line N)
**Reported by:** <reviewer names>
**Issue:** ...
**Fix:** ...
```

Severity levels: `CRITICAL` | `HIGH` | `MEDIUM` | `LOW`

Rules:

- Lead with highest severity
- Only include confirmed issues (not style-only)
- End with summary line: total findings by severity
