# Plan: Provider-Specific Model Parameters (Reasoning Variants)

## Goal

Extend nikcli's model system so every provider has its own reasoning parameters with variants (effort levels, budgets, etc.) similar to opencode's approach.

## Current State

### nikcli's variants() Function (`src/provider/transform.ts`)

Current implementation has:

- Hardcoded switch on `model.api.npm` (npm package identifier)
- Per-provider variant definitions with limited flexibility
- No version-aware effort selection for model families
- Limited reasoning effort arrays

### opencode's Improvements (to adopt)

1. **Version-aware reasoning efforts**: Helper functions for computing effort levels
   - `openaiReasoningEfforts(apiId, releaseDate)` - Handles GPT-5.1, 5.2, codex, chat variants
   - `gpt5Version(apiId)` - Extracts version number
   - `gpt5CodexReasoningEfforts(apiId)` - Codex-specific efforts
   - `gpt5ChatReasoningEfforts(apiId)` - Chat-specific efforts

2. **Per-provider effort helpers**:
   - `anthropicAdaptiveEfforts(apiId)` - Returns adaptive efforts or null
   - `googleThinkingLevelEfforts(apiId)` - Google-specific thinking levels
   - `googleThinkingBudgetMax(apiId)` - Budget calculation

3. **Model-specific effort arrays**:

   ```typescript
   const OPENAI_GPT5_1_EFFORTS = ["none", ...WIDELY_SUPPORTED_EFFORTS]
   const OPENAI_GPT5_2_PLUS_EFFORTS = [...OPENAI_GPT5_1_EFFORTS, "xhigh"]
   const OPENAI_GPT5_PRO_EFFORTS = ["high"]
   const OPENAI_GPT5_CODEX_3_PLUS_EFFORTS = ["none", ...WIDELY_SUPPORTED_EFFORTS, "xhigh"]
   ```

4. **Release date awareness**:
   - `OPENAI_NONE_EFFORT_RELEASE_DATE = "2025-11-13"`
   - `OPENAI_XHIGH_EFFORT_RELEASE_DATE = "2025-12-04"`

## Implementation Plan

### Phase 1: Enhance transform.ts helper functions

**File**: `packages/nikcli/src/provider/transform.ts`

1. Add effort array constants:

```typescript
const OPENAI_GPT5_1_EFFORTS = ["none", ...WIDELY_SUPPORTED_EFFORTS]
const OPENAI_GPT5_2_PLUS_EFFORTS = [...OPENAI_GPT5_1_EFFORTS, "xhigh"]
const OPENAI_GPT5_CODEX_EFFORTS = [...WIDELY_SUPPORTED_EFFORTS, "xhigh"]
const OPENAI_GPT5_PRO_EFFORTS = ["high"]
const OPENAI_GPT5_CHAT_EFFORTS = ["medium"]
const OPENAI_NONE_EFFORT_RELEASE_DATE = "2025-11-13"
const OPENAI_XHIGH_EFFORT_RELEASE_DATE = "2025-12-04"
```

2. Add helper functions (similar to opencode):

- `gpt5Version(apiId)` - Extract version from "gpt-5.x" pattern
- `gpt5CodexReasoningEfforts(apiId)` - Codex-specific efforts
- `gpt5ChatReasoningEfforts(apiId)` - Chat-specific efforts
- `openaiReasoningEfforts(apiId, releaseDate)` - Main OpenAI effort selector
- `googleThinkingLevelEfforts(apiId)` - Google thinking levels
- `googleThinkingBudgetMax(apiId)` - Google budget calculation

3. Refactor `variants()` switch cases to use these helpers

### Phase 2: Model Schema Enhancement

**File**: `packages/nikcli/src/provider/models.ts`

Add optional fields to Model schema:

```typescript
variants: Schema.optional(
  Schema.Record(Schema.String, Schema.Record(Schema.String, Schema.Unknown)),
)
// Add:
reasoningEfforts?: string[]  // Available efforts
reasoningBudgets?: Record<string, number>  // Token budgets per effort
supportsReasoningSummary?: boolean

```

### Phase 3: @nikcli-ai/llm Provider Variants

**Files**: `packages/llm/src/providers/*.ts`

Add variant definitions for each provider:

- `openai.ts` - OpenAI reasoning effort options
- `anthropic.ts` - Anthropic thinking budgets
- `google.ts` - Google thinking levels
- `openai-compatible.ts` - OpenAI-compatible variants
- `openrouter.ts` - OpenRouter reasoning options

### Phase 4: Config Schema Updates

**File**: `packages/nikcli/src/config/config.ts`

Add model-level variant overrides:

```typescript
provider: {
  [providerId: string]: {
    models?: {
      [modelId: string]: {
        variants?: {
          [variantName: string]: Record<string, unknown>
        }
      }
    }
  }
}
```

### Phase 5: TUI Updates (if needed)

Update model selection UI to display available variants.
