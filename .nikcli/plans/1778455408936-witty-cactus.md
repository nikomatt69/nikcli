# Plan: Fix Background Agents Dialog Not Showing Content

## Problem

The Background Agents dialog (`/bg-agents`) doesn't show content after the last commit.

## Root Cause

The dialog only looks for jobs under `props.sessionID` (passed from the command palette), but:

1. Background jobs are stored under `parentSessionID` in the delegation manager
2. The command palette uses `session()?.parentID ?? route.sessionID` as the sessionID
3. If syncing hasn't completed when dialog renders, `store.background_job[sessionID]` is empty

## Solution

Modify `dialog-bg-agents.tsx` to:

1. Also look for jobs in the parent session (if current session has a parent)
2. Collect jobs from both current and parent session for display

## Files to Modify

- `src/cli/cmd/tui/routes/session/dialog-bg-agents.tsx`

## Implementation

```typescript
// Add helper function
function isActiveStatus(status: string) {
  return status === "running" || status === "synthesizing"
}

// Modify options memo to check both current and parent session
const options = createMemo((): DialogSelectOption<BgOption>[] => {
  const out: DialogSelectOption<BgOption>[] = []

  // Get jobs from current session and parent session
  const currentJobs = sync.background.list(props.sessionID)
  const parentSession = sync.session.get(props.sessionID)
  const parentJobs = parentSession?.parentID ? sync.background.list(parentSession.parentID) : []
  const allJobs = [...currentJobs, ...parentJobs]

  const jobs = [...allJobs].sort((a, b) => {
    const activeA = isActiveStatus(a.status)
    const activeB = isActiveStatus(b.status)
    if (activeA !== activeB) return activeA ? -1 : 1
    const hiddenA = dismissed().has(a.rootDelegationID)
    const hiddenB = dismissed().has(b.rootDelegationID)
    if (hiddenA !== hiddenB) return hiddenA ? 1 : -1
    return b.updatedAt - a.updatedAt
  })

  for (const job of jobs) {
    if (dismissed().has(job.rootDelegationID)) continue
    // ... rest of existing code
  }
})
```
