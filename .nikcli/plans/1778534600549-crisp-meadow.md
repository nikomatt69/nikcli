# Enterprise Analytics Dashboard for nikcli

## Overview

Create enterprise-level analytics with persistent data storage and best-in-class terminal charts using braille sub-pixel rendering. Inspired by the reference screenshots showing stacked bar charts, KPI cards, per-day tables, and model family breakdowns.

## Architecture

### Data Flow

```
Server (session/message lifecycle) → Analytics Service → Storage JSON snapshots
                                                              ↓
TUI Dialog ← AnalyticsAggregator (merges live sync data + historical snapshots)
                    ↓
        Braille Line Charts / Unicode Bar Charts / Heatmaps
```

### Storage Keys (JSON file-based, existing Storage.Service)

- `["analytics", "global"]` → `GlobalAnalytics` (running totals, updated per-event)
- `["analytics", "daily", "YYYY-MM-DD"]` → `DailyAnalytics` (per-day aggregates)
- `["analytics", "session", sessionID]` → `SessionAnalytics` (per-session snapshot)
- `["analytics", "tool", "YYYY-MM-DD"]` → `ToolDailyAnalytics` (per-tool per-day)

### Retention: 365 days of daily snapshots (~700KB/year)

### 5. NEW: `src/cli/cmd/tui/component/chart-braille-line.tsx` (~350 lines)

**Purpose**: High-resolution braille line chart component.

**Core algorithm**:

```
1. Map data points to virtual pixel grid (width×2, height×4)
2. Bresenham's line algorithm between consecutive points
3. For each character cell, compute braille bitmask from 2×4 sub-pixels
4. Character = U+2800 + bitmask
5. Color per cell = dominant series color
```

**Components**:

- `BrailleLineChart` — Multi-series line chart with grid, axes, legend
- `BrailleAreaChart` — Filled area below line
- `BrailleBarChart` — High-res vertical bars

**Props**: series[], width, height, xLabels, yFormat, showGrid, showLegend, showAxis, fillBelow, smoothCurve

**Multi-series**: Each series rendered on same grid. OR'd braille masks. Color = topmost series.

## Braille Rendering Technical Details

### Character Encoding (U+2800–U+28FF)

```
Dot layout:        Bit mapping:
col 0  col 1       Bit 0 (0x01) → row 0, col 0
┌────┬────┐        Bit 1 (0x02) → row 1, col 0
│ 1  │ 8  │ row 0  Bit 2 (0x04) → row 2, col 0
│ 2  │ 16 │ row 1  Bit 3 (0x08) → row 0, col 1
│ 4  │ 32 │ row 2  Bit 4 (0x10) → row 1, col 1
│ 64 │ 128│ row 3  Bit 5 (0x20) → row 2, col 1
└────┴────┘        Bit 6 (0x40) → row 3, col 0
                   Bit 7 (0x80) → row 3, col 1
```

Each character cell = 2px wide × 4px tall = 8× resolution over single char.

### Bresenham Line on Virtual Grid

```typescript
function drawBrailleLine(grid, x0, y0, x1, y1) {
  // Standard Bresenham with braille dot placement
  // Each virtual pixel maps to: cell = floor(vx/2), floor(vy/4)
  //                           dot = BRAILLE_BITS[vy%4][vx%2]
}
```

### Area Fill

After drawing line, fill all dots from line down to baseline with dimmer color.
