# Interactive Burst Logo for nikcli TUI

## Summary

Port opencode's interactive burst logo to nikcli's TUI. Features:

- Click-and-hold to charge, release to burst ripple effect
- Ambient shimmer rings cycling from logo center
- Sound effects (charge hum + burst pulse)
- Works on the TUI home screen logo

## Files to Modify

### 1. `src/cli/cmd/tui/component/logo.tsx` ⭐ PRIMARY

Complete rewrite with burst animation. Key changes:

**New imports:**

```typescript
import { BoxRenderable, MouseButton, MouseEvent, RGBA, TextAttributes } from "@opentui/core"
import { For, createMemo, createSignal, onCleanup, onMount, type JSX } from "solid-js"
```

**Animation constants:**

- `PERIOD = 4600` - shimmer cycle duration
- `LIFE = 1020` - burst ring lifetime
- `HOLD = 90` - hold before charge starts
- `CHARGE = 3000` - full charge time
- Plus ~20+ animation tuning constants from opencode

**Core functions to port:**

1. `mapGlyphs()` - maps ASCII to glyph cells
2. `wave()` - ripple wave animation
3. `field()` - charge field at cursor
4. `trace()` - lightning trace effect
5. `bloom()` - afterglow on selected glyph
6. `idle()` - ambient shimmer rings
7. `renderLine()` - enhanced char rendering with dynamic colors

**Mouse handling:**

```typescript
<box
  position="absolute"
  onMouseDown={(evt) => press(evt.x - box.x, evt.y - box.y, evt.time)}
  onMouseUp={() => burst()}
/>
```

### 2. `src/cli/cmd/tui/routes/home.tsx`

Pass `idle` prop to enable ambient shimmer:

```tsx

```

## Implementation Notes

### Logo Adaptation

Nikcli logo is 6 lines × ~22 chars split into left/right. Adapt `build()`:

```typescript
const DEFAULT = build({
  left: LOGO_LEFT,
  right: LOGO_RIGHT,
})
```

### Shadow Handling

Current shadow markers (`_`, `^`, `~`) are preserved:

- `_` = full shadow cell
- `^` = letter top, shadow bottom (▀)
- `~` = shadow top only (▀)

### Sound Integration

Already wired in `sound.ts`. Call at right moments:

- `Sound.start()` - when mouse held past HOLD threshold
- `Sound.stop(140)` - when releasing
- `Sound.pulse(scale)` - on burst release

### Colors

Use existing nikcli theme:

- Left logo: `theme.textMuted`
- Right logo: `theme.text`
- Burst: `tint(fg, theme.primary, intensity)`
- Peak: white `RGBA.fromInts(255,255,255)`

## Verification Steps

1. **Build check**: `bun run build`
2. **Typecheck**: `bun run typecheck`
3. **Run TUI**: `bun run dev`
4. **Test interaction**:
   - Hover over logo → cursor should indicate interactivity
   - Click and hold → charge sound plays, logo dims slightly
   - Release → burst ripple emanates, pulse sound plays
   - Wait → ambient shimmer rings cycle continuously
5. **Config test**: `bg_pulse: false` in config hides ambient
