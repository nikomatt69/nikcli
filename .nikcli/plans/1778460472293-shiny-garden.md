# Enhanced Analytics Dialog Plan

## Context

The current `dialog-analytics.tsx` only shows basic stats from sessions and messages. The user wants comprehensive analytics covering **all sessions, projects, workspaces, and more** with enhanced charts featuring colors and legends.

## Available Data Sources (already in sync store)

| Data                | Source                         | Key Stats                                       |
| ------------------- | ------------------------------ | ----------------------------------------------- |
| **Sessions**        | `sync.data.session`            | title, created, updated, archived, tokens, cost |
| **Messages**        | `sync.data.message[sessionID]` | role, tokens, cost, model, provider             |
| **Parts**           | `sync.data.part[messageID]`    | type (tool, text, etc.), state, title           |
| **Todos**           | `sync.data.todo[sessionID]`    | status, priority                                |
| **Workspaces**      | `sync.data.workspaceList`      | status, type, config                            |
| **Background Runs** | `sync.data.background_job`     | status, agent, duration, errors                 |
| **Providers**       | `sync.data.provider`           | id, models, cost                                |

## Implementation Plan

### Step 1: Create Analytics Aggregator Utility

**File**: `src/cli/cmd/tui/util/analytics-aggregator.ts`

Create a single function `aggregateAnalytics()` that processes all sync data and returns typed stats:

```typescript
interface AggregatedStats {
  global: GlobalStats
  projects: ProjectStats[]
  workspaces: WorkspaceStats
  sessions: SessionStats[]
  providers: Map<string, ProviderStats>
  days: DayStats[]
  backgroundRuns: BackgroundRunStats
  toolUsage: ToolUsageStats
  todos: TodoStats
}
```

### Step 2: Add Enhanced Chart Components

**File**: `src/cli/cmd/tui/component/dialog-analytics.tsx`

Add new chart components with colors and legends:

#### MultiLineChart - Multi-series line chart

```typescript
// Features:
// - Colored lines per series (using theme colors)
// - Data point markers (●) on each line
// - Bottom legend with color squares (■) + labels
// - Horizontal grid lines for readability
// - Y-axis numeric labels on left
// - X-axis date labels below
// - Normalized scaling for comparing different magnitudes

function MultiLineChart(props: {
  series: {
    label: string
    data: { label: string; value: number }[]
    color: string // from theme
  }[]
  width: number
  height: number
}) {
  // Colors mapping:
  // - primary (blue): Input tokens
  // - error (red): Output tokens
  // - warning (yellow): Reasoning tokens
  // - success (green): Cost / Messages
  // - accent (cyan): Cache tokens
}
```

#### StackedBarChart - Stacked horizontal bars

```typescript
// Each segment is a different color
// Labels on left, values on right
// Percentage labels within bars for large segments

function StackedBarChart(props: {
  segments: { label: string; value: number; color: string }[]
  width: number
  showPercentages?: boolean
})
```

#### ChartLegend - Color-coded legend

```typescript
// Row of colored squares + labels
// Optional values shown in bold

function ChartLegend(props: { items: { label: string; color: string; value?: string }[]; layout?: "row" | "column" })
```

### Step 3: Tab-Based Layout

**6 tabs with keyboard navigation**:

```
┌─ ◈ Analytics ─────────────────────── [←][→] [esc] ─┐
│                                                       │
│  [Overview] [Tokens] [Projects] [Runs] [Tools] [Sessions]  │
│  ────────────────────────────────────────────────────  │
│                                                       │
│  <Tab Content>                                        │
│                                                       │
└───────────────────────────────────────────────────────┘
```

**Tab 1: Overview**

- Global stats header
- Multi-line daily chart: Tokens, Cost, Messages overlaid with legend
- Provider summary

**Tab 2: Tokens**

- Token breakdown: Stacked bars with colors (input=blue, output=red, reason=yellow, cache=cyan)
- Percentage labels
- 14-day trend sparkline with colored dots
- Efficiency metrics with color indicators

**Tab 3: Projects**

- Project cards with mini stat bars
- Color-coded by VCS type

**Tab 4: Runs**

- Background runs stacked bar: running=yellow, completed=green, error=red, cancelled=gray
- Success rate with progress indicator
- Top agents with usage bars

**Tab 5: Tools**

- Tool usage horizontal bars with color gradient
- Success rate inline indicators

**Tab 6: Sessions**

- Active vs archived counts
- Top sessions by tokens
- Workspaces summary
