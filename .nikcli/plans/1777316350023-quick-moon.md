# nikcli Test Suite Plan

## Overview

Create a comprehensive, production-ready test suite for the nikcli CLI package with full coverage and benchmarks for all modules.

## Requirements

- **Full coverage** with benchmarks for all modules
- **By module organization** - mirrors src/ structure (test/id/, test/session/, etc.)
- **Self-contained tests** - no shared utilities package
- **Deterministic benchmarks** with warmup and performance assertions

## Test Infrastructure

### Current Setup (Keep)

- **Runner**: Bun test
- **Config**: `bunfig.toml` (10s timeout, coverage enabled)
- **Pattern**: `describe/it` blocks, `performance.now()` for benchmarks
- **Isolation**: Temp directories + environment variables

## Test Patterns

### Unit Test Template

```typescript
import { describe, expect, it } from "bun:test"

describe("ModuleName", () => {
  describe("methodName", () => {
    it("should do something", () => {
      const result = methodName(input)
      expect(result).toBe(expected)
    })

    it("should throw on invalid input", () => {
      expect(() => methodName(invalid)).toThrow()
    })

    it("should handle edge case", () => {
      // edge case test
    })
  })
})
```

### Benchmark Template

```typescript
import { describe, expect, it } from "bun:test"

describe("ModuleName Benchmark", () => {
  it("methodName performance", () => {
    const warmup = 100
    const iterations = 10000
    const input = prepareInput()

    // Warmup
    for (let i = 0; i < warmup; i++) methodName(input)

    // Measure
    const start = performance.now()
    for (let i = 0; i < iterations; i++) methodName(input)
    const elapsed = performance.now() - start
    const perOp = elapsed / iterations

    console.log(`${iterations} ops: ${elapsed.toFixed(2)}ms (${perOp.toFixed(4)}ms/op)`)
    expect(perOp).toBeLessThan(0.001) // < 1ms per operation
  })
})
```

### Integration Test Template

```typescript
import { afterAll, afterEach, beforeEach, describe, expect, it } from "bun:test"
import fs from "fs/promises"
import os from "os"
import path from "path"

const testHome = await fs.mkdtemp(path.join(os.tmpdir(), "nikcli-test-"))
process.env.NIKCLI_TEST_HOME = testHome
process.env.NIKCLI_DISABLE_PROJECT_CONFIG = "1"

afterAll(async () => {
  await fs.rm(testHome, { recursive: true, force: true })
})

describe("Integration tests", () => {
  it("full workflow", async () => {
    // Test full flow with real storage
  })
})
```

## Verification

### Run Tests

```bash
# Run all tests
bun test

# Run specific module
bun test test/session/

# Run with coverage
bun test --coverage

# Run benchmarks only
bun test --match "*benchmark*"
```

### Expected Outcomes

- All tests pass
- Coverage report shows >80% for core modules
- Benchmarks complete within timeouts
- No test pollution between modules

## Notes

- Keep tests self-contained (no shared utilities)
- Use deterministic inputs for benchmarks
- Include warmup iterations
- Add performance assertions to benchmarks
- Group related tests in describe blocks
