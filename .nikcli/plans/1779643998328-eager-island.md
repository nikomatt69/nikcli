# Plan: TUI Subagent/Background Task Management Enhancement

## Goal

Improve TUI management of subagents and background tasks in the **bottom of the prompt area**:

1. Job frame showing active background jobs with counts and details
2. Monitor section showing active shell monitors
3. Ability to open monitors from background tasks
4. Unified, consistent, and responsive design
5. Better overall architecture for subagent/monitor management

## User Requirements (from clarifications)

- Jobs/monitors should appear **in the bottom of the prompt area** (where existing job count is)
- **Responsive** in width
- **Unified and coherent** with existing elements
- **All features**: Jobs + Monitors + linking

## Implementation Plan

### Phase 1: Create Unified Frame Component (`src/cli/cmd/tui/component/`)

#### 1.1 `prompt-frames.tsx` - Unified Jobs + Monitors Frame

A collapsible frame at the bottom of the prompt area showing:

- **Jobs section**: Active background jobs with title, agent, status
- **Monitors section**: Active monitors with title, status, preview
- **Responsive**: Adapts width to terminal dimensions
- **Clickable**: Navigate to job sessions or open monitor logs
- **Keyboard shortcuts**: j, m, x for job/monitor actions

```typescript
type PromptFramesProps = {
  sessionID: string
  jobs: JobItem[]
  monitors: MonitorInfo[]
  collapsed?: boolean
  onToggle?: () => void
  onOpenJob: (job: JobItem) => void
  onOpenMonitor: (monitor: MonitorInfo) => void
  onCancelJob: (jobID: string) => void
  onCancelMonitor: (monitorID: string) => void
}
```

### Phase 2: Enhance Monitor Data Extraction

#### 2.1 Add Monitor Info Type

```typescript
type MonitorInfo = {
  id: string
  title: string
  command: string
  status: "running" | "complete" | "error" | "timeout" | "cancelled"
  logPath?: string
  preview?: string
}
```

#### 2.2 Create `util/monitor-helpers.ts`

Extract monitors from message parts (similar to `background.ts`):

```typescript
export function getActiveMonitors(sync: UseSync, sessionID: string): MonitorInfo[]
export function getMonitorsForSession(sync: UseSync, sessionID: string): MonitorInfo[]
```

### Phase 3: Integrate into Prompt Component

#### 3.1 Modify `component/prompt/index.tsx`

- Import and render `PromptFrames` component
- Extract monitors from message parts
- Pass callbacks for job/monitor actions
- Maintain backward compatibility with existing job tracking

### Phase 4: Create Monitor Log Dialog

#### 4.1 Create/enhance `routes/session/dialog-monitor-log.tsx`

Dialog for viewing monitor output:

- Read log from monitor's logPath
- Live updates for running monitors
- Search/filter functionality

### Phase 5: Enhance Background Agents Dialog

#### 5.1 Modify `routes/session/dialog-bg-agents.tsx`

- Better visual hierarchy
- Unified styling with prompt frames
- Search/filter functionality

## Keyboard Navigation

| Key                | Action                  |
| ------------------ | ----------------------- |
| `j`                | Toggle jobs section     |
| `m`                | Toggle monitors section |
| `Enter` on job     | Open job session        |
| `Enter` on monitor | Open monitor log        |
| `x`                | Cancel focused item     |
| `Escape`           | Collapse frame          |
