# nikcli Architecture Analysis Report

## Executive Summary

**Package**: `packages/nikcli` - A CLI agent system built with Bun, TypeScript, and Effect framework.

**Key Technologies**:

- **Runtime**: Bun with TypeScript ESM modules
- **Functional Programming**: Effect library for dependency injection and effects
- **Validation**: Zod schemas (converted from Effect Schema via `zod()` helper)
- **Storage**: Hierarchical JSON files with SQLite for specific data
- **Architecture**: Service-based DI with AsyncLocalStorage context propagation

## 8. Key Architectural Patterns

### 8.1 Dependency Injection with Effect

```typescript
// Define service
class MyService extends Context.Service<MyService, Interface>()("My.Service") {}

// Create layer
const layer = Layer.effect(
  MyService,
  Effect.gen(function* () {
    return MyService.of({
      /* implementations */
    })
  }),
)

// Use in effect
const result = await runPromiseWithLayer(
  layer,
  Effect.gen(function* () {
    const service = yield* MyService
    return yield* service.operation()
  }),
)
```

### 8.2 AsyncLocalStorage for Context

Context propagation via `AsyncLocalStorage` for request-scoped data without explicit passing.

### 8.3 Error Handling Pattern

```typescript
// Tools return error info in output, don't throw
return {
  title: "Error",

}
```

### 8.4 Parallel Execution

- **Task Tool**: Launch subagents with `background: true`
- **Delegation**: Monitor via `delegator` and `delegation` tools
- **Batch**: Parallel execution via `batch` tool
