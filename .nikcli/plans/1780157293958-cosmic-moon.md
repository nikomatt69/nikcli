# Plan: Integrate @nikcli-ai/llm Native Runtime in nikcli

## Overview

Replace the AI SDK-only streaming path with `@nikcli-ai/llm`'s native runtime, while keeping AI SDK as a fallback. This follows opencode's pattern.

## Current State

- `src/session/llm.ts`: Uses `LLMCore.stream()` from AI SDK with `ProviderTransform.message()` for transforms
- `src/provider/llm-client.ts`: Comment-only file documenting the transition
- `LLMRuntime.prepareRequest()` used only for request inspection (non-fatal debug logging)

## Target Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                    LLM.stream()                            │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ if flags.experimentalNativeLlm                       │   │
│  │   native = LLMNativeRuntime.stream()                 │   │
│  │   if supported → return Stream<LLMEvent>             │   │
│  │   else → log fallback reason                        │   │
│  └─────────────────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ else (default) → AI SDK path                         │   │
│  │   result = streamText(...)                           │   │
│  │   return toLLMEvents(result.fullStream)              │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

## Implementation Steps

### Step 1: Update `src/provider/llm-client.ts`

Export the Effect Layer from `@nikcli-ai/llm/route`:

```typescript
import { Effect, Layer } from "effect"
import { LLMClient, RequestExecutor, WebSocketExecutor } from "@nikcli-ai/llm/route"
import type { LLMClientService } from "@nikcli-ai/llm/route"

export const defaultLayer = Layer.suspend(() =>
  LLMClient.layer.pipe(Layer.provide(Layer.mergeAll(RequestExecutor.defaultLayer, WebSocketExecutor.layer))),
)

export type { LLMClientService }
```

### Step 2: Update `src/effect/index.ts`

Add `LLMClient.Service` to the default layer composition (if not already present).

### Step 3: Create `src/session/llm/native-runtime.ts`

Bridge between nikcli's data model and `@nikcli-ai/llm`:

```typescript
import * as Stream from "effect/Stream"
import type { LLMEvent } from "@nikcli-ai/llm"
import type { LLMClientService } from "@nikcli-ai/llm/route"
import type { ModelMessage, Tool } from "ai"
import { ProviderTransform } from "@/provider/transform"

export type StreamResult =
  | { readonly type: "supported"; readonly stream: Stream.Stream<LLMEvent, unknown> }
  | { readonly type: "unsupported"; readonly reason: string }

export function stream(input: StreamInput): StreamResult {
  // 1. Check if provider is supported (openai, anthropic, opencode)
  // 2. Build LLMRequest using ProviderTransform.message() and ProviderTransform.providerOptions()
  // 3. Call llmClient.stream()
  // 4. Return Stream<LLMEvent, unknown> or unsupported reason
}
```

Key differences from opencode:

- Use `@nikcli-ai/llm` instead of `@opencode-ai/llm`
- Use `@/provider/transform` for message/provider transforms
- No OAuth fetch override (unless needed)

### Step 4: Create `src/session/llm/ai-sdk.ts`

Adapter to convert AI SDK `fullStream` events to `LLMEvent`:

```typescript
import type { LLMEvent } from "@nikcli-ai/llm"
import { FullStreamPart } from "ai"

export function adapterState() { ... }
export function toLLMEvents(state: AdapterState, event: FullStreamPart): LLMEvent[] { ... }
```

This pattern exists in opencode's `llm/ai-sdk.ts`.

### Step 5: Create `src/session/llm/request.ts`

Move request building logic from `src/session/llm.ts`:

- `buildLLMRequest()` - convert nikcli's stream input to `LLMRequest`
- `hasToolCalls()` - check if messages contain tool calls
- `toLLMContentPart()` - convert AI SDK content parts to LLM content parts

### Step 6: Update `src/session/llm.ts`

Modify the `stream()` function:

1. Import `LLMClient.Service` from Effect context
2. Add runtime seam with feature flag:
   ```typescript
   if (flags.experimentalNativeLlm) {
     const native = LLMNativeRuntime.stream({ llmClient, ... })
     if (native.type === "supported") return native.stream
   }
   ```
3. Use AI SDK fallback with `LLMAISDK.toLLMEvents()` adapter
4. Remove `LLMRuntime.prepareRequest()` debug logging (now covered by native runtime)

### Step 7: Add Feature Flag

Add to `src/flag/flag.ts`:

```typescript
experimentalNativeLlm: boolean // default: false
```

Or use existing `RuntimeFlags.Service` if available.

## Verification

1. **Feature flag off (default)**:
   - `bun run dev` - Verify normal streaming still works
   - Test with OpenAI, Anthropic, Google, OpenRouter providers

2. **Feature flag on**:
   - Set `experimentalNativeLlm: true` in config
   - `bun run dev` - Verify native runtime is selected
   - Check logs for `"llm.runtime": "native"`

3. **Fallback test** (with flag on):
   - Test with a non-supported provider (e.g., Azure, custom)
   - Verify fallback to AI SDK with log: `"native runtime unavailable; falling back to ai-sdk"`

4. **Run tests**:
   ```bash
   bun test test/session/llm
   ```

## Notes

- opencode's implementation uses `@opencode-ai/llm` - we use `@nikcli-ai/llm` (same package, different org)
- The native runtime only supports OpenAI, Anthropic, and opencode providers initially
- AI SDK fallback ensures backward compatibility with all providers
