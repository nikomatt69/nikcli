# Plan: Background Task Wake Notification

## Problem

Background tasks (subtasks with `background: true`) run fire-and-forget. When they complete, the parent agent is **not notified** — it must actively poll via `delegation(action="read")` or `delegator(action="summarize")` to get results.

Monitors, by contrast, use a **wake mechanism** that injects a completion message into the parent session via `SessionPrompt.prompt()`, triggering the LLM loop so the parent agent automatically learns the result.

## Goal

Make background tasks behave like monitors: when the **delegator finishes synthesizing** (i.e., the job is fully complete), inject a notification message into the parent session so the parent agent wakes up and receives the result automatically.

## Approach

Add a `wake` function in `task.ts` (mirroring `monitor/manager.ts:wake()`) and call it after delegator finalization in `launchBackgroundSubtask()`.

### Changes

#### 1. Add `wakeParentSession()` function (after existing helpers, ~line 430)

```typescript
async function wakeParentSession(
  parentSessionID: string,
  result: {
    jobId: string
    delegationId: string
    delegatorDelegationId: string
    description: string
    status: string
    summary: string
  },
) {
  try {
    const summaryLines = result.summary.split("\n").slice(0, 30).join("\n")
    const lines = [
      `Background task "${result.description}" finished.`,
      `Status: ${result.status}`,
      `Job ID: ${result.jobId}`,
      "",
      "Result:",
      summaryLines,
      "",
      `Use delegation(action="read", delegationId="${result.delegatorDelegationId}") for the full result.`,
    ]

    await runPromiseWithLayer(
      SessionPrompt.defaultLayer,
      withCurrentInstance(
        Effect.gen(function* () {
          const sessionPrompt = yield* SessionPrompt.Service
          return yield* sessionPrompt.prompt({
            sessionID: parentSessionID,
            parts: [
              {
                type: "text",
                text: lines.join("\n"),
              },
            ],
          })
        }),
      ),
    )
  } catch (error) {
    log.error("failed to wake parent session for background task", {
      error: String(error),
      jobId: result.jobId,
    })
  }
}
```

This uses the exact same `runPromiseWithLayer(SessionPrompt.defaultLayer, withCurrentInstance(...))` pattern already imported in this file.

## Why wake on delegator finalization (not worker)

The **delegator** is the supervisor that synthesizes results from worker(s) and potentially spawns follow-up agents. The job is only "done" when the delegator finishes. Waking on worker completion would give the parent incomplete results.

## Data Flow (after change)

```
Parent agent calls task(background: true)
  → launchBackgroundSubtask() returns immediately with metadata
  → Parent continues working...

  [Background: worker runs → worker finalizes]
  [Background: delegator synthesizes → delegator finalizes]
  → wakeParentSession(parentSessionID, { summary, ... })
    → SessionPrompt.prompt({ sessionID: parentSessionID, parts: [...] })
      → Creates user message in parent session
      → loop(parentSessionID) runs LLM
      → Parent agent receives the result as if user sent a message
```
