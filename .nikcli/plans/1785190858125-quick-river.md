# Plan: assess the latest 20 upstream PRs

## Goal and scope

Analyze the first 20 commits currently on anomalyco/opencode's `v2` branch and recommend what nikcli should integrate. All 20 commits are single-parent, PR-linked changes, so this window is also exactly 20 PRs: `#39174` through `#39058`. This is an analysis-only task; no product code will be changed.

## Verified baseline

- Upstream scope: `8b4b0d67` (PR #39174) through `766aaf44` (PR #39058), all dated 2026-07-27.
- Local baseline: clean `live-main` at `f9f602263`; none of the 20 exact SHAs is in local object history.
- Architecture: upstream now uses `packages/core` and `packages/tui`; nikcli keeps the corresponding runtime and TUI under `packages/nikcli/src`, with significant custom Effect services, SDK/server behavior, plugins, and TUI features. Direct cherry-picks are inappropriate; recommendations must be semantic ports.

## Assessment method

1. For each PR, inspect the upstream diff, changed tests, behavior, and prerequisites with `git show` in the managed upstream clone.
2. Map the behavior to nikcli using local source, tests, and history, then label it one of:
   - **Integrate/adapt**: missing behavior with clear local value.
   - **Already covered**: equivalent or stronger local behavior exists; only retain upstream as regression evidence.
   - **Defer**: useful, but lifecycle/architecture risk is too high for the current payoff.
   - **Skip**: tied to an upstream-only UI/runtime path or not applicable locally.
3. For every label, cite the upstream SHA/PR and at least one local path proving the conclusion.
4. Rank only the genuinely missing pieces, grouping dependent PRs so partially superseded series are not ported commit-by-commit.
