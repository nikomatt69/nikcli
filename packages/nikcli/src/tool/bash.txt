Execute a shell command (bash/PowerShell). Default cwd: ${directory}.

Use for: git, package managers, docker, builds, one-shot scripts.
Do NOT use for file CRUD/search — prefer Read, Write, Edit, Glob, Grep, LS.

Rules:
- Prefer `workdir` over `cd path && …`. Quote paths with spaces.
- Short, bounded commands only. Long-running (dev servers, watchers, installs that stream) → `monitor`.
- Use the project package manager (e.g. bun), never mix npm/pnpm/yarn ad hoc.
- Prefer dedicated tools over find/grep/cat/sed/awk/echo when available.
- Optional `timeout` ms (default 120000). Output truncates at ${maxLines} lines / ${maxBytes} bytes (full log on disk).
- Describe the command in 5–10 words via the description field.
- Never skip git hooks (`--no-verify`) unless the user asks. No force-push to main/master.
- Do not commit unless the user explicitly requests a commit.
