Monitor and supervise background delegation jobs without blocking the main agent.

Actions:
- `status`: get current status (running, synthesizing, complete, error, etc.) — also returns Worker Session and Delegator Session IDs for TUI navigation
- `progress`: preview current output of a running/completed job
- `summarize`: brief summary of latest results
- `cancel`: stop a running job

Use the delegator:
- After launching `task(background: true)`, to check progress before it finishes
- For a quick status update without reading the full result
- To get a concise summary of completed background tasks

Background tasks automatically wake the parent session on completion with a result summary — you do NOT need to poll. Use the delegator only when you want progress before the wake arrives. The delegator reads structured delegation state; it does not execute the task or spawn agents.

Example:
1. Launch: `task(description="explore auth", prompt="...", subagent_type="explore", background=true)`
2. Continue other work
3. Check status: `delegator(delegationId="...", action="status")`
4. Wake arrives automatically on completion
