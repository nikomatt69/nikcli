Edit files with a stripped-down, file-oriented diff format. Envelope:

*** Begin Patch
[ one or more file sections ]
*** End Patch

Each section starts with a header:
- `*** Add File: <path>` — new file. Every following line is `+` (initial contents).
- `*** Delete File: <path>` — remove file. Nothing follows.
- `*** Update File: <path>` — patch existing. Optionally `*** Move to: <new>` for rename.

Update bodies are unified diff hunks (`@@`, ` ` / `-` / `+` lines).

Rules:
- Prefix new lines with `+` even when creating a file.
- `*** Begin Patch` must be the first non-empty line; `*** End Patch` the last.
- Move destinations must be in edit permission patterns.
- Unicode minus `U+2212` and en/em dashes are normalized to ASCII `-`.

Example:
```
*** Begin Patch
*** Add File: hello.txt
+Hello world
*** Update File: src/app.py
*** Move to: src/main.py
@@ def greet():
-print("Hi")
+print("Hello, world!")
*** Delete File: obsolete.txt
*** End Patch
```
