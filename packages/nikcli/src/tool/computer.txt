Control a computer's screen, mouse, and keyboard ("computer use").

Default: sandbox mode — an isolated Linux desktop in a container. No real-time takeover of the user. First action may take a while while the desktop image is built.

Loop: screenshot → decide → action → screenshot again. Coordinates are screen pixels from top-left.

Actions: screenshot / capabilities / screen_size / mouse_move / left_click / right_click / middle_click / double_click / left_click_drag / type / key / scroll / status / stop.

Modes (config `computer.mode`):
- sandbox (default) — containerized Linux. Needs colima on macOS. Desktop runs in the VM, not on the Mac.
- host — drives the user's real machine in real time. Only when the user asks. Needs Screen Recording + Accessibility on macOS.

Never perform destructive or irreversible actions without explicit user instruction.
