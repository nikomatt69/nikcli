Run an orchestration script in a confined interpreter that calls other tools programmatically. Intermediate tool results are NOT added to the conversation context — only the value your program returns (plus `console.log`) comes back. Keeps the context window clean when chaining many tool calls.

Use for:
- Processing many files with aggregation/filter
- Looping tool calls without bloating context
- Transforming tool outputs before returning
- Multi-step operations where only the final result matters

It's a restricted JS subset, NOT a real JS runtime:
- No `import`/`require`, `fetch`, `process`, filesystem, timers, or host globals
- No `eval`, `Function`, classes, or generators
- Tool calls start eagerly; `await` every call whose completion matters — anything still running when the program returns is interrupted
- Args and results are plain JSON
- Omitted `return` yields the final top-level expression

Tools are under the `tools` namespace as async functions.

Example:
```
const files = await tools.glob({ pattern: "src/**/*.ts" })
const todos = []
for (const f of files.split("\n")) {
  const content = await tools.read({ filePath: f })
  if (content.includes("TODO")) todos.push(f)
}
return todos
```
