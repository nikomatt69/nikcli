Control iOS Simulators and Android Emulators: list, boot, shutdown, install apps, capture screenshots, read logs, wipe, interact with UI (touch, swipe, type, launch apps, open URLs, send button events), and AppleScript-based automation (click UI elements by accessibility label, type via keyboard, press key combos, read accessibility tree).

Requires `xcrun` (macOS, iOS Simulator) or `adb`/`emulator` (Android SDK).

Basic actions:
- list: List all simulators/emulators with state (booted/shutdown). Use platform to filter.
- boot: Start a simulator/emulator by device_id.
- shutdown: Stop a running simulator/emulator.
- install: Install an .ipa or .apk on a booted device. Use path or url.
- screenshot: Capture the device screen as PNG. Returns file path.
- logs: Read device logs. Use lines and filter to narrow output.
- wipe: Reset device to factory state (deletes all data).
- open: Open the Simulator app (iOS) or launch default emulator (Android).
- touch: Tap at x,y coordinates on screen. Use long_press for long tap.
- swipe: Swipe from (x1,y1) to (x2,y2). For scroll up/down/left/right.
- type: Type text via simctl keyboard.
- launch: Launch an app by bundle ID (e.g., 'com.apple.mobilesafari').
- openurl: Open a URL (https, tel, mailto, maps, sms).
- key: Send hardware button: home, lock, volume_up, volume_down, siri, apple_pay.

AppleScript automation (iOS only, requires Simulator app):
- focus: Bring Simulator app to front.
- click_label: Click a UI element by its accessibility label (button, text field, static text).
- type_text: Type text using AppleScript keystroke simulation (works with keyboard events).
- press_key: Press a key with optional modifiers. Keys: return, escape, tab, space, delete, arrow keys, a-z, 0-9. Modifiers: command, shift, option, control.
- command_key: Send Cmd+Key shortcut (e.g., key="a" for Cmd+A select all).
- accessibility_tree: Get the UI accessibility tree of the simulator window.
- window_bounds: Get Simulator window position and size.
- wait_booted: Wait for device to finish booting (returns when state=booted).

Workflow example:
1. list (get device_id) → 2. boot → 3. wait_booted → 4. screenshot → 5. launch app → 6. click_label/type_text → 7. screenshot (verify)
