Convert text to speech and play it on the machine speakers (non-blocking). Supports ElevenLabs and OpenRouter.

ElevenLabs audio tags (inline in `text`): `[laughs] [sighs] [excited] [sad] [angry] [whispers] [shouts] [dramatically] [calmly] [British accent] [strong French accent]`.

Parameters:
- text: required; include audio tags as needed
- provider: elevenlabs | openrouter
- stability: 0–1 (default 0.5; lower = more expressive)
- similarityBoost: 0–1 (default 0.75)
- speed: 0.5–2 (default 1.0)
- volume: 0–2 (default 1.0)
- voiceId, modelId, outputFormat: provider-dependent defaults
- timeoutMs: default 30000

Usage guidance:
- Short bursts for important state changes — completion, errors requiring attention, questions needing user input
- Keep messages concise (1–2 sentences)
- Audio plays on the device running nikcli
