Manage Expo development workflow: start dev server, build with EAS, install packages, publish OTA updates, list build profiles, and run environment diagnostics.

Requires Node.js and npx installed.

Actions:
- start: Start Expo dev server (Metro bundler). Optionally open on ios/android/web.
- build: Build app with EAS Build. Specify platform and optional profile.
- install: Install Expo-compatible packages via 'expo install'.
- publish: Publish OTA update to Expo servers.
- profiles: List EAS build profiles from eas.json.
- doctor: Check Node.js, Expo CLI, EAS CLI availability.

Examples:
- start: { action: "start", platform: "ios" }
- build: { action: "build", platform: "all", profile: "production" }
- install: { action: "install", packages: ["expo-camera", "expo-media-library"] }
- publish: { action: "publish", message: "Bug fix update" }
