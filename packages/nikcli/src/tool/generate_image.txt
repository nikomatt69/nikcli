Generate images from a text prompt.

Preset generators (use `generator: "<name>"`):
- OpenAI (needs OPENAI_API_KEY): gpt_image, gpt_image_mini, gpt_image_1_5, dall_e_3
- Google Imagen 4 (GOOGLE_GENERATIVE_AI_API_KEY): imagen_4, imagen_4_ultra, imagen_4_fast
- xAI (XAI_API_KEY): grok_imagine, grok_imagine_pro
- OpenRouter-routed (OPENROUTER_API_KEY): nanobanana, nanobanana_openai
- Together AI (TOGETHER_API_KEY): flux_dev, flux_schnell, flux_pro, sdxl

Bypass presets with `provider` + `model` (e.g. `provider: "openai", model: "gpt-image-1"`).

Parameters:
- prompt (required): text prompt
- generator: preset name (optional)
- provider: provider ID override (wins over generator and config)
- model: model ID override (wins over generator and config)
- n: 1–4 (default 1)
- size: "WxH" (e.g. "1024x1024")
- aspectRatio: "W:H" (e.g. "16:9")
- seed: deterministic seed
- providerOptions: provider-specific passthrough

Resolution order: `params.provider+model` > `params.generator` > `config.image` > preset default (gpt_image).
