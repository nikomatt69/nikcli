- Search the web - performs real-time web searches and returns content from the most relevant pages
- Provides up-to-date information for current events and recent data
- Supports configurable result counts and returns the content from the most relevant websites
- Use this tool for accessing information beyond knowledge cutoff
- Searches are performed automatically within a single API call
- Results are returned as blocks of title, URL, publication date when known, and page content

Usage notes:
  - The search backend is configured by the user (Exa by default). The livecrawl, type and
    contextMaxCharacters parameters only apply to Exa and are ignored by other backends
  - Supports live crawling modes: 'fallback' (backup if cached unavailable) or 'preferred' (prioritize live crawling)
  - Search types: 'auto' (balanced), 'fast' (quick results), 'deep' (comprehensive search)
  - Configurable context length for optimal LLM integration

Today's date is {{date}}. You MUST use this year when searching for recent information or current events
- Example: If today is 2025-07-15 and the user asks for "latest AI news", search for "AI news 2025", NOT "AI news 2024"
